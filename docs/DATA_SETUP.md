# 실제 자료 연결 안내

## 현재 확인 가능한 범위 (2026-09-07)

지도·지역 선택, 최대 5개 비교, 연도별 공급 조회, 상세 출처, 자료 가져오기와 관심목록을 제공합니다. 전체 부동산 시장을 실시간 수집한 서비스는 아닙니다.

- 공식 고시·LH 공급계획 13건은 기존 확인 자료입니다.
- 추가 통계 22건은 `lib/verified-data.json`에 있습니다. 한국부동산원·국토교통부 발표를 인용한 언론 보도에서 확인한 수치이며 기관 원표 직접 대조 전입니다. 각 항목의 링크와 상태에 실제 확인 경로를 명시했습니다.
- 가격 변동률은 2026-08-31 기준 **주간 아파트** 통계입니다. 월간 지수나 개별 단지 상승률로 바꾸어 해석하지 마세요. 경북 주간 값과 대부분 시군구 값은 아직 등록되지 않았습니다.
- 울산 분양·준공은 **1~7월 누계**입니다. 2025년 준공도 같은 기간입니다. 연간 전체 공급량으로 표시하거나 준공을 실제 입주로 취급하지 않습니다.
- API 연결 없이도 위 확인본은 표시됩니다. 새로고침은 저장된 자료를 다시 불러오며, 외부기관 전체 자료를 수집하는 버튼은 아닙니다.

### 청약홈 연결 순서

1. 포털에 로그인하고 위 청약홈 서비스 활용신청을 완료합니다.
2. 승인 상태와 이용한도를 확인합니다.
3. 배포 서버의 비밀 환경변수에 `PUBLIC_DATA_KEY`로 **Decoding** 인증키를 저장합니다. 로컬 개발은 `.env.example`을 복사한 `.env`를 사용합니다. 키를 GitHub 파일·이슈·개발일지에 넣지 않습니다.
4. 사이트의 **자료 관리 → 청약홈 공고 수집**에서 기간을 선택하고 수집 실행을 누릅니다. 최대 93일, 결과가 많으면 기간을 줄이세요.
5. 수집 건수와 실제 모집공고의 공급량·마감일을 대조합니다. 승인 지연, 한도 초과 또는 외부 API 장애면 오류를 확인합니다.

현재 대화에 실키가 제공되지 않아 연동 성공을 확인하지 않았습니다. 먼저 활용신청을 완료하고 승인 여부를 알려주세요. 배포 환경의 안전한 비밀값 설정 방식으로 연결해야 합니다. 키 한 개로 가격지수·실거래·공급·모든 정비사업이 동시에 연동되는 것은 아닙니다.

### 키 없이 자료 보완하기

기관에서 내려받은 CSV·XLSX·PDF 원본을 준비하면 기준기간과 범위를 검증해 가져오기용 JSON으로 변환할 수 있습니다. 사이트 자료 관리의 양식에는 실제 수치와 출처를 입력하세요. 같은 집계는 같은 ID로 갱신합니다. 시도 총계와 구군 세부자료를 중복 합산하지 않습니다. `전체집계`는 해당 연도·범위 전체를 확인한 경우에만 사용합니다.
