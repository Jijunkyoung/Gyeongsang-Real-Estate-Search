# 실제 자료 연결 안내

## 현재 확인 가능한 범위 (2026-09-07)

지도·지역 선택, 최대 5개 비교, 연도별 공급 조회, 상세 출처, 자료 가져오기와 관심목록을 제공합니다. 전체 부동산 시장을 실시간 수집한 서비스는 아닙니다.

- 공식 고시·LH 공급계획 13건은 기존 확인 자료입니다.
- 추가 통계 22건은 `lib/verified-data.json`에 있습니다. 한국부동산원·국토교통부 발표를 인용한 언론 보도에서 확인한 수치이며 기관 원표 직접 대조 전입니다. 각 항목의 링크와 상태에 실제 확인 경로를 명시했습니다.
- 가격 변동률은 2026-08-31 기준 **주간 아파트** 통계입니다. 월간 지수나 개별 단지 상승률로 바꾸어 해석하지 마세요. 경북 주간 값과 대부분 시군구 값은 아직 등록되지 않았습니다.
- 울산 분양·준공은 **1~7월 누계**입니다. 2025년 준공도 같은 기간입니다. 연간 전체 공급량으로 표시하거나 준공을 실제 입주로 취급하지 않습니다.
- API 연결 없이도 위 확인본은 표시됩니다. 새로고침은 저장된 자료를 다시 불러오며, 외부기관 전체 자료를 수집하는 버튼은 아닙니다.

### 청약홈 연결 순서

1. 포털에 로그인하고 위 청약홈 서비스 활용신청을 완료합니다.
2. 승인 상태와 이용한도를 확인합니다.
3. 배포 서버의 비밀 환경변수에 `PUBLIC_DATA_KEY`로 **Decoding** 인증키를 저장합니다. 로컬 개발은 `.env.example`을 복사한 `.env`를 사용합니다. 키를 GitHub 파일·이슈·개발일지에 넣지 않습니다.

4. 사이트의 **자료 관리 → 청약홈 공고 수집**에서 기간을 선택하고 수집 실행을 누릅니다. 입력 한도는 93일이지만 기관 응답 안정성을 위해 14일 이내를 권장합니다.
5. 수집 건수와 실제 모집공고의 공급량·마감일을 대조합니다. 승인 지연, 한도 초과 또는 외부 API 장애면 오류를 확인합니다.

### 국토교통부 아파트 매매 실거래가

1. 공공데이터포털에서 `국토교통부_아파트 매매 실거래가 상세 자료`를 활용신청합니다.
2. 승인된 일반 인증키(Decoding)를 Sites 비밀 환경변수 `RTMS_API_KEY`에 저장합니다.
3. 부동산 도구에서 시군구·분양가·전용면적·기간을 선택해 조회합니다. 창원시와 포항시는 구까지 선택해야 합니다.
4. 인증키는 브라우저로 전달되지 않고 서버에서만 사용합니다. 신고 해제 건은 비교에서 제외합니다.

인증키는 배포 환경의 비밀값으로만 관리합니다. 키 한 개로 가격지수·실거래·공급·모든 정비사업이 동시에 연동되는 것은 아닙니다.

청약홈 수집기는 모집공고 원본과 함께 해당 공고의 공급 세대수를 연도별 `분양·부분집계` 근거로 저장합니다. 같은 공고 번호는 새 행을 추가하지 않고 갱신합니다. 모집공고 합계는 해당 지역의 모든 주택 공급량이 아닙니다. APT 공고에 특별공급, 1순위 해당지역·기타지역, 2순위 해당지역·기타지역 접수일이 제공되면 각각 별도의 달력 일정으로 저장합니다.

자료를 직접 등록할 때 날짜 성격은 `공식 발생·게시일`과 `자료 확인일` 중에서 선택합니다. 자료 확인일은 최신 확인 시점을 기록하는 값일 뿐 사업 일정이 아니므로 달력에 표시하지 않습니다. 고시번호가 있는 자료는 기관 고시목록이나 토지이음의 고시일을 우선하며, 검색·수집일을 고시일로 대체하지 않습니다.

### KOSIS 연결 순서

1. KOSIS OpenAPI에서 인증키를 발급합니다.
2. 배포 서버의 비밀 환경변수 `KOSIS_API_KEY`에 저장합니다.
3. 사이트의 **자료 관리 → KOSIS 연간 인허가 통계 수집**에서 연도를 지정합니다.
4. 수집 결과는 `인허가`로 저장되며 분양·준공·입주 물량으로 바꾸어 해석하지 않습니다.

KOSIS와 청약홈의 최근 실행 시각·상태·저장 건수는 관리자 화면에 표시됩니다. GitHub Actions가 매일 00:15 UTC(한국시간 09:15)에 KOSIS 최근 6개 연도와 청약홈 최근 90일·향후 180일 공고를 수집합니다. 청약홈은 기관 응답 안정성을 위해 14일 단위로 나눠 조회합니다.

워크플로 파일이 `main`에 반영될 때는 2020년 1월 1일부터 현재까지의 청약홈
APT 모집공고를 한 번 역수집합니다. 과거 공고는 달력에 다시 쌓지 않고 `분양`
연도별 공급량의 시·구·군 근거만 저장합니다. 이 합계는 청약홈 APT 모집공고의
공급 세대수 합계이며, 지역 전체 인허가·준공·입주 물량과는 동일하지 않습니다.

향후 120일 조회는 아직 게시되지 않은 모집공고를 예측하지 않습니다. 10월 이후
정확한 청약 접수일은 청약홈 공식 모집공고가 게시된 다음 자동 반영됩니다. 공고에
입주 예정월만 공개된 경우 `앞으로 12개월 공개 일정`에 월 단위로 표시됩니다.

GitHub Actions 인증은 저장소 Secret 대신 GitHub OIDC 서명을 사용합니다. 서버는 저장소명, `main` 브랜치, 워크플로 파일, 실행 유형, 만료시간과 서명을 모두 확인합니다. 개인 수집 토큰 값은 계속 Sites 비밀 환경변수에만 보관합니다.

### Solar AI 연결

- 업스테이지 키는 `UPSTAGE_API_KEY`, 모델은 `UPSTAGE_MODEL`에 저장합니다.
- 질문과 관련된 등록 자료가 있을 때만 Solar에 해당 자료와 질문을 전달합니다.
- 답변은 저장 자료 범위 밖의 사실을 추정하지 않도록 제한하며 원문 출처를 함께 표시합니다.

### 키 없이 자료 보완하기

기관에서 내려받은 CSV·XLSX·PDF 원본을 준비하면 기준기간과 범위를 검증해 가져오기용 JSON으로 변환할 수 있습니다. 사이트 자료 관리의 양식에는 실제 수치와 출처를 입력하세요. 같은 집계는 같은 ID로 갱신합니다. 시도 총계와 구군 세부자료를 중복 합산하지 않습니다. `전체집계`는 해당 연도·범위 전체를 확인한 경우에만 사용합니다.
